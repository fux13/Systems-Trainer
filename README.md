# King Air 350 Systems Trainer Prototype v0.5

## Main change
The Fuel schematic has been corrected and simplified visually. LEFT WING FUEL feeds the LEFT ENGINE path; RIGHT WING FUEL feeds the RIGHT ENGINE path. Crossfeed is shown separately between the two engine-supply paths.

Electrical keeps its previous detail level, but the details now appear only after selecting a bus.

Open `index.html` directly. The prototype works offline and requires no external libraries.

Training prototype only. Not a replacement for approved AFM/QRH documentation.
