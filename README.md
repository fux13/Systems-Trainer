# King Air 350 Systems Trainer Prototype v0.10

## Electrical display corrections
- Retains the aircraft-form schematic and the operator-provided D-CFME battery position between the right engine cowling/nacelle and fuselage.
- Battery feed is now visually separated from logical bus placement.
- Added explicit TIE/contactors instead of implying a permanent direct Center/Triple-Fed connection.
- Added a central logical busbar to make electrical distribution easier to read without suggesting a literal equipment installation position.
- Left and right generator feeds are drawn more symmetrically.
- External Power now has a visible feed into the distribution area.
- Physical equipment remains solid-outline; logical bus elements remain dashed-outline.
- Existing detailed QRH consumer and CB information remains available on bus selection.

The aircraft silhouette is a learning visualization, not an engineering-scale installation drawing.

Open `index.html` directly or publish via GitHub Pages. No external dependencies are required.
