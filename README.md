# King Air 350 Interactive Systems Trainer

A new modular prototype based solely on the user-provided:
- KA35F PTM 350/360,
- FCS B350 eQRH,
- KA35F AFM,
- D-CFME POH/AFM.

## Implemented
- PTM chapter navigation for Chapters 1–18, excluding the requested Weight & Balance and Performance modules.
- Learn, Explore, Failure and Quiz modes.
- Interactive Electrical, Fuel and Pneumatic core modules.
- Clickable QRH-derived electrical consumer/CB detail data.
- Local progress storage.
- Responsive and offline single-file design suitable for GitHub Pages.
- Source-controlled placeholders for remaining chapters, preventing unsupported content from being invented.

## Run
Open `index.html` directly or upload it to a GitHub Pages repository root.

Training use only. It does not replace current approved AFM, POH or eQRH material.
