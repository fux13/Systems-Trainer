# King Air 350 Systems Trainer Prototype v0.4

Offline, single-file HTML training prototype.

## New in v0.4
- Detailed electrical Bus Explorer based on the FCS B350 QRH bus connection tables.
- Bus-level consumer and circuit-breaker references for Left/Right Generator Bus, Triple-Fed Bus, Center Bus, Battery Bus and the three avionics buses.
- Interactive source/tie logic retained from v0.3.
- Fuel and pneumatic trainers retained.

## Run
Open `index.html`. No server or internet connection is required.

## GitHub Pages
Place `index.html` and this README in the repository root and enable GitHub Pages.

## Important
Training prototype only. It is not approved operational documentation and must not replace the current AFM/QRH.
