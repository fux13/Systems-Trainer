# King Air 350 Systems Trainer

Offlinefähiger PWA-Prototyp zum interaktiven Lernen des King Air 350 Electrical Systems.

## GitHub Pages veröffentlichen

1. Neues GitHub-Repository erstellen, zum Beispiel `ka350-systems-trainer`.
2. Den vollständigen Inhalt dieses ZIP-Archivs in die oberste Ebene des Repositorys hochladen. `index.html` darf nicht in einem zusätzlichen Unterordner liegen.
3. In GitHub `Settings` öffnen.
4. Links `Pages` auswählen.
5. Unter `Build and deployment` die Quelle `Deploy from a branch` wählen.
6. Branch `main` und Ordner `/(root)` auswählen, dann speichern.
7. Nach ein bis drei Minuten zeigt GitHub die öffentliche Pages-Adresse an.

## iPhone-Installation

1. Die GitHub-Pages-Adresse in Safari öffnen.
2. Teilen-Symbol antippen.
3. `Zum Home-Bildschirm` auswählen.
4. Nach dem ersten vollständigen Laden kann die App offline geöffnet werden.

## Dateien

- `index.html`: Oberfläche und Seitenstruktur
- `styles.css`: Design und responsive Darstellung
- `data.js`: Lektionen, Fragen und Fehlerszenarien
- `app.js`: Interaktion, Systemzustand und Fortschritt
- `manifest.webmanifest`: PWA-Konfiguration
- `service-worker.js`: Offline-Cache
- `icons/`: App-Symbole

## Wichtiger Hinweis

Der Trainer ist ein didaktischer Prototyp und keine zugelassene Trainings- oder Betriebsunterlage. Für reale Verfahren, Limitationen und Flugentscheidungen gelten ausschließlich die genehmigten, zur konkreten Flugzeugkonfiguration passenden Unterlagen.
